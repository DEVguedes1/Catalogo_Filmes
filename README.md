# Catálogo de Filmes

Sistema web para gerenciamento de um catálogo de filmes, desenvolvido como projeto acadêmico para a disciplina de Desenvolvimento Web.

O sistema permite ao usuário cadastrar, visualizar, editar e excluir filmes, utilizando HTML, CSS e JavaScript.

## 🚀 Funcionalidades

* Cadastrar um novo filme
* Visualizar filmes cadastrados
* Editar informações de um filme
* Excluir um filme
* Marcar filme como assistido ou não assistido
* Avaliar o filme com uma nota
* Armazenar os dados no LocalStorage
* Validar os campos do formulário
* Interface responsiva

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 📋 Dados dos filmes

Cada filme poderá possuir as seguintes informações:

* **Título**
* **Gênero**
* **Ano de lançamento**
* **Nota**
* **Status**

## 🔄 Operações CRUD

### Create — Criar

O usuário poderá preencher um formulário e cadastrar um novo filme no catálogo.

### Read — Ler

Os filmes cadastrados serão exibidos na tela em formato de tabela ou cards.

### Update — Atualizar

O usuário poderá selecionar um filme e alterar suas informações.

### Delete — Excluir

O usuário poderá remover um filme do catálogo.

## 💾 Armazenamento

Os dados serão armazenados utilizando o `LocalStorage` do navegador. Dessa forma, os filmes continuarão disponíveis mesmo depois de atualizar ou fechar a página.

## 👥 Equipe

A equipe será dividida por funcionalidades. Dessa forma, todos os integrantes terão contato com **HTML, CSS e JavaScript**, participando de diferentes partes do desenvolvimento.

### Nicolas — Cadastro de filmes

* Criar o formulário de cadastro no HTML
* Estilizar o formulário com CSS
* Implementar o cadastro dos filmes com JavaScript
* Trabalhar na validação dos campos

### Adones — Listagem de filmes

* Criar a área onde os filmes serão exibidos
* Desenvolver os cards ou tabela de filmes
* Implementar a função de buscar e exibir os filmes
* Trabalhar na responsividade da listagem

### Vini — Edição de filmes

* Criar a funcionalidade de editar filmes
* Desenvolver o formulário de edição
* Implementar a alteração dos dados com JavaScript
* Estilizar a interface de edição

### Nycholas — Exclusão e armazenamento

* Criar a funcionalidade de excluir filmes
* Implementar a remoção dos filmes com JavaScript
* Trabalhar com o `LocalStorage`
* Garantir que os dados permaneçam salvos após atualizar a página

### 🔧 Integração e revisão

Após cada integrante finalizar sua parte, toda a equipe irá trabalhar em conjunto para:

* Revisar o funcionamento do CRUD
* Integrar todas as funcionalidades
* Corrigir possíveis erros
* Padronizar o HTML, CSS e JavaScript
* Testar o `LocalStorage`
* Testar a responsividade
* Validar os formulários
* Preparar o projeto para apresentação

## 📂 Estrutura do projeto

```text
catalogo-filmes/
│
├── index.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── README.md
```

## 🎯 Objetivo

O objetivo do projeto é aplicar na prática os conceitos de desenvolvimento web, principalmente manipulação do DOM, eventos, formulários, armazenamento de dados no navegador e implementação das operações CRUD com JavaScript.

## 📌 Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta no VS Code ou outro editor.
3. Abra o arquivo `index.html` no navegador.
4. Utilize o formulário para cadastrar e gerenciar os filmes.
